Enable Swagger UI in .NET 10

Four steps to get an interactive API page opening automatically when you run your project. Tick each step as you practise it.

0 of 4 steps done

1Install the NuGet package

Install Swashbuckle.AspNetCore in your project using the NuGet Package Manager.

Or from a terminal inside the project folder:

dotnet add package Swashbuckle.AspNetCore

2Update the Program.cs file

Modify the HTTP request pipeline by adding this code:

// Configure the HTTP request pipeline.
if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

UseSwagger() serves the generated JSON document; UseSwaggerUI() serves the interactive page. The IsDevelopment() check keeps it off in production.

Extra tip: Swashbuckle also needs its services registered before builder.Build(). If Swagger shows an error or empty page, add: 
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();

3Update the launchSettings.json file

Open Properties/launchSettings.json and update both the http and https profiles. Set these properties in each profile:

"launchBrowser": true,
"launchUrl": "swagger"

For example, your HTTPS profile should look like this:

"https": {
  "commandName": "Project",
  "dotnetRunMessages": true,
  "launchBrowser": true,
  "launchUrl": "swagger",
  "applicationUrl": "https://localhost:7039;http://localhost:5082",
  "environmentVariables": {
    "ASPNETCORE_ENVIRONMENT": "Development"
  }
}

4Run the project

Save your changes, rebuild the project, and run your application. Swagger UI should open automatically in your browser.

dotnet build
dotnet run --launch-profile https

If the browser doesn’t open, visit https://localhost:7039/swagger (use the port from your own launchSettings.json).
